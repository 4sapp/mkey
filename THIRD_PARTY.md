# Third-party material

## Jorts interface

Mkey adapts the window layout, editable title, bottom action bar, theme popover,
and preferences layout of [Jorts](https://codeberg.org/elly-code/jorts).

Jorts credits:

- 2017–2024 Lainsce.
- 2025 contributions from the Ellie Commons community.
- 2025–2026 Stella & Charlie.

The referenced Jorts source files identify `GPL-3.0-or-later`. Mkey's C source and
interface adaptation use the same license; see [LICENSE](LICENSE). Mkey is an
independent application. Jorts is written in Vala; Mkey is written in C.

## Reference sound excerpts

The five PCM files in `data/sounds/` are short excerpts from Hayyoth's video
[I am Human, not AI. This is my story.](https://www.youtube.com/watch?v=gLn7F22HngI).
They were selected to reproduce the reference supplied for this project.
[Sample provenance](data/sounds/SOURCE.txt) records the source timestamps and format.

The GPL license for Mkey's code does not grant a license to the original video or
these excerpts. No separate redistribution license from the video author is
asserted. Replace these samples with your own recordings when distributing a
sound pack under a different license.

## Mkey 2 reference excerpts

The five PCM files in `data/sounds/mkey2/` are short excerpts from
[srD4vo's Día 717: Creando una Startup Exitosa](https://www.youtube.com/watch?v=w59fc10mgyM&t=7222s).
The reference includes voice and background audio. Offline processing isolates
percussive events and reduces the background before mapping the clips to keys
and mouse buttons. [Provenance](data/sounds/mkey2/SOURCE.txt) records the timestamps
and processing. No license to the original recording is asserted by the GPL
license on the application source.
